**The dashboard summarises metabolic, inflammatory and trace-element responses
around a 1-minute Sit-to-Stand Test (STST).**

Metabolic (Glucose, Lactate), Inflammatory (WBC, GRA, LYM, NLR, SII, SIRI),
Trace Elements (Selenium, SELENOP, Zinc, Free Zinc, Copper, Iron).

Each parameter can be switched on/off independently; at least one always stays
active.

**Adjustment toggle** — Unadjusted vs. hemoconcentration-adjusted. Parameters
without adjusted values (NLR, Free Zinc) are automatically greyed out in
adjusted mode.

**Display toggle** — % change from pre-exercise baseline (default, all
parameters on a common scale) or absolute values.

**Exercise zone** — amber shaded area from −1 min to 0 min marking the
1-minute STST, with a bold dashed line at 0 min and a "STST" label.

**±1 SD bands** — drawn as a transparent fill around each line. Each parameter
in the legend is also clickable to individually show/hide lines.
